# DCS Visual Lab

A bilingual study site for Distributed and Concurrent Systems, available in English and Finnish.

[Open DCS Visual Lab](https://escaladus.github.io/dcs-visual-lab/)

Created by [Denis](https://github.com/Escaladus) with assistance from OpenAI Codex.
Based on Simo Juvaste’s *Distributed and Concurrent Systems* course handout (University of Eastern Finland, Spring 2026, 3621415). [UEF Moodle](https://moodle.uef.fi/)

## Run locally

Requires Node.js 24.

```sh
npm ci
npm run dev
```

Run `npm run build` to create the static site in `dist/`.
